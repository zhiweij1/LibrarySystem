# 图书管理系统 (Library Management System)
一款基于 Qt 6 和 C++17 开发的桌面图书管理工具。

## 编译环境要求
框架: Qt 6.10.1 (需安装 Widgets, Sql 模块)
标准: C++17

## 数据库与依赖说明
数据库: 系统运行后会自动在程序目录下生成 SQLite 数据库文件 library.db。
