# 图书管理系统 (Library Management System)

一款基于 Qt 6 和 C++17 开发的桌面图书管理工具，使用 Excel（.xlsx）作为数据存储，无需数据库服务，适合中小型图书馆的日常借还管理。

## 功能

- 书籍查询：按条码、书名、作者、出版社模糊查询，支持状态筛选与分页
- 借书：扫码添加待借清单，批量办理借书
- 还书 / 续借：输入读者卡号或直接扫描书籍条码（自动定位读者并勾选归还），同一界面勾选归还或续借，一次提交批量处理
- 催还提醒：按天数查询即将到期 / 已逾期的借阅，按读者聚合展示
- 读者管理：增删改查读者，支持搜索与注销
- 封面预览：列表中显示缩略图，点击查看大图

## 编译环境

| 项 | 要求 |
|---|---|
| Qt | 6.11.1（需安装 Widgets、Gui 模块，使用 GuiPrivate 私有头） |
| 编译器 | MinGW 13.1.0 64-bit（或其他支持 C++17 的编译器） |
| 构建工具 | CMake ≥ 3.16 |
| 标准 | C++17 |

## 数据存储与依赖

- **数据文件**：单一 Excel（.xlsx）文件，包含三个 Sheet：
  - 主 Sheet：书名 / 作者 / 出版社 / 数量 / 封面图文件号 / 条形码 / 分类号 / 备注 / 状态
  - `_readers`：姓名 / 卡号 / 电话 / 是否注销
  - `_borrows`：id / 读者卡号 / 书籍条码 / 借书日期 / 应还日期 / 归还日期
- **封面图**：存放在数据文件同目录下的 `covers/` 文件夹，文件名与"封面图文件号"对应。
- **QXlsx**：第三方 Excel 读写库（MIT 协议），作为子模块位于 `third_party/QXlsx`，由 CMake 自动引入，无需单独安装。
- **运行时数据目录**：`<用户文档目录>/LibrarySystemData/`，存放日志 `log.txt`、配置 `settings.ini`（借期天数 `borrow/days`，默认 30 天；每人最多可借数量 `borrow/maxBooks`，默认 3 本）。

> 首次运行时若未配置数据文件路径，程序会弹出文件选择对话框让用户指定 .xlsx 文件。

## 数据安全（备份机制）

- **保存前备份**：每次写入数据前，先将当前文件复制为 `<数据文件>.bak`（覆盖旧备份）。若写入失败，自动从 `.bak` 恢复原文件，避免数据损坏。

## 代码规范

- `.clang-format`：基于 LLVM 风格。
- `.clang-tidy`：启用 `clang-diagnostic-*`、`llvm-*`、`misc-*`、`readability-identifier-naming` 等检查，命名约定为类 / 枚举 / 成员 / 参数 / 变量 CamelCase、函数 camelBack。
